# Guia simple para el examen

## Que voy a demostrar
1. Crear backup.
2. Borrar datos.
3. Recuperar datos.

## Antes de empezar
1. Abrir terminal en la raiz del proyecto.
2. Confirmar que el `.env` apunta a Railway.

## Paso a paso (corto) - desde la aplicacion

### Paso 1: Ir a Backups
1. Iniciar sesion como ADMIN.
2. Abrir menu lateral.
3. Entrar a **Backups**.

### Paso 2: Crear backup
1. En la tarjeta "Crear backup", presionar **Crear backup**.
2. (Opcional) escribir nombre, por ejemplo `pre-examen`.
Que mostrar: aparece mensaje de exito y archivo en la tabla de backups.

### Paso 3: Borrar datos
1. En la tarjeta "Borrar datos", presionar **Borrar datos del sistema**.
2. Confirmar.
Que mostrar: en otros modulos ya no hay datos.

### Paso 4: Restaurar datos
1. Presionar **Restaurar ultimo backup**.
2. (Alternativa) elegir un archivo en el selector y usar **Restaurar seleccionado**.
Que mostrar: los datos vuelven a aparecer.

## Texto simple para decir en voz alta
1. "Ahora voy a crear un backup desde la aplicacion."
2. "Ahora voy a borrar los datos para simular perdida de informacion."
3. "Ahora restauro desde el backup y recupero todo, tambien desde la aplicacion."
4. "Con esto queda demostrado backup y recuperacion."
